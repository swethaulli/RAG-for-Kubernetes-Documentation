# RAG-for-Kubernetes-Documentation
This project implements a Retrieval-Augmented Generation (RAG) system for Kubernetes documentation. It involves scraping official Kubernetes docs, applying various chunking strategies (fixed-length, overlapping, section-based), generating embeddings with open-source models (all-MiniLM-L6-v2, distilbert-base-nli-mean-tokens), and storing them in a FAISS vector database. A baseline LLM-only QA system (gpt2) was developed, followed by a complete RAG system that retrieves relevant document chunks and uses the LLM to generate grounded answers, with robust context length management. The project also includes a detailed experimental plan, curated evaluation questions, and defined metrics for performance assessment.
